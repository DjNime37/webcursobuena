# Web en PHP (Curso)

## 🚀 Instrucciones de uso

1. **Descargar (o clonar) el repositorio** y guardarlo en la siguiente ruta local: `C:\xampp\htdocs\webenphpcurso`

2. **Ejecuta npm install** (sirve para descargar e instalar las herramientas, librerías y códigos para que se ejecute el javascript).

3. **Iniciar XAMPP**:
   * Arranca los módulos **Apache** y **MySQL**.

4. **Acceder a la aplicación**:
   * Abre tu navegador y dirígete a: [http://localhost/webenphpcurso/](http://localhost/webenphpcurso/)

5. **Inicio de sesión y Registro**:
   * Como ya existen usuarios registrados, puedes hacer clic directamente en el botón **Iniciar Sesión**.
   * Si eliges la opción **Registrarse**, se abrirá una nueva pestaña solicitando tus datos. La base de datos se creará de forma automática al completar el registro.
   * *Nota:* En esa nueva pestaña puedes ingresar los datos indicados o cualquier otro que prefieras.

¡ENJOY! 🎉

---
> ⚠️ **Importante:** Por el momento el proyecto no ejecuta código `.php` interno, aunque los archivos utilicen dicha extensión.
